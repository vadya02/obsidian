
Задача процесса управления сроками состоит в том, чтобы контролировать ход работ таким образом, чтобы не было отклонений от плана по времени


Основные процессы:
- Планирование управления расписанием - создание документации для исполнения контроля расписания проекта
- Определение состава работ
- Определение взаимосвязей между работами
- Определение длительности работ
- Оценка ресурсов компании
- Разработка расписания
- Контроль расписания

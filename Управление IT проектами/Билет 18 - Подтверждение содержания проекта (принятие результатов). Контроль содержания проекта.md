
Подтверждение содержания проекта - процесс приемки результатов проекта с помощью например аудита. В данный процесс не входят проверка качества о корректности работы

Контроль содержания проекта - процесс контроля изменений, происходящих в проекте. Нужен для того, чтобы проект в ходе работ не отклонялся от заданного содержания.

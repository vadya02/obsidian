
Критический путь проекта - цепочка задач, при изменении которой происходит неизбежное изменение сроков реализации проекта. Критический путь - самая длинная цепочка работ по проекту

Руководитель должен в первую очередь мониторить работы на критическом пути

Оценка критического пути происходит путем прямого и обратного прохода

Прямой проход - для каждой работы оценивается ранний старт и финиш начиная с первой

Обратный проход - для каждой работы оценивается поздние старт и финиш, начиная с последней работы

Работы у которых ранние и поздние даты совпадают, находятся на критическом пути


Процесс обеспечения качества проекта - процесс, необходимый для соответствия продукта и работ проекта определенным стандартам в рамках проекта

Данный процесс проводится на протяжении всего жизненного цикла проекта

Обеспечение качества проводится на основе заранее определенного плана управления качеством

Примеры:
- Тестирование продукта
- Поддержание документации проекта в актуальном состоянии
